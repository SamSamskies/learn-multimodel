Lesson 8 · ~25 minutes

Bridge OpenRouter Adapter

Gateway literacy becomes product when it fits the Provider contract — without rewriting the page API.

Lessons 1–7 taught you to call OpenRouter with evidence: routers, cost, catalog, failover, Fusion, Pareto. Your mission’s proving ground is Inference Bridge. Today you draft the adapter that turns that literacy into a selectable provider beside OpenAI and Ollama.

Two contracts, one adapter

Surface Who sees it Rule
IPA (window.inference) Web pages Do not change — chunks, errors, permission story stay stable
Provider (internal) Extension only Clone openai.js / ollama.js; register in registry.js

Bridge’s README says the quiet part out loud: implement the same shape as the existing providers, register it, extend Options if you need another credential. The page still gets accepted → delta* → done (or an InferenceError). Keys never leave the extension (Bridge README).

What you clone from OpenAI

OpenRouter’s Chat Completions path is OpenAI-compatible. Bridge’s OpenAI adapter already streams SSE to /v1/chat/completions and maps usage. Your OpenRouter file is that adapter with three intentional diffs:

  1. URL → https://openrouter.ai/api/v1/chat/completions
  2. Auth → OpenRouter key (sk-or-…), not an OpenAI platform key
  3. Models → provider/model slugs (curated list now; live GET /models later)
{
  id: "openrouter",
  label: "OpenRouter",
  requiresApiKey: true,
  defaultModel: "openrouter/free",
  models: [ "openrouter/free", "openai/gpt-4o-mini", … ],
  streamChat({ apiKey, model, messages, signal, onDelta }) { … }
}
Optional attribution
OpenRouter’s quickstart allows HTTP-Referer and X-OpenRouter-Title so your app can appear on their rankings. Nice for Bridge; not required for the IPA contract.

Key storage: don’t paper over it

Today Bridge stores one field: openaiApiKey. Reusing it for OpenRouter “works” for a demo and lies forever after. Prefer a dedicated openrouterApiKey (Options label + service-worker branch) so users can keep both providers configured. Host permission: https://openrouter.ai/*.

Scope for this lesson
Practice ships a portable Provider in this repo and smoke-tests streaming. Porting into Bridge (registry, manifest, Options, tests) is the checklist at the end — same shape, product wiring.
