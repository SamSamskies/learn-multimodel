OpenRouter Basics

One OpenAI-compatible endpoint. Many models. You still own routing decisions.

Endpoints

Prefer provider/model slugs from openrouter.ai/models. Router aliases like openrouter/free pick among matching models for you — log the returned model to see what ran. Some catalog entries use a ~ prefix — copy the exact string from the docs.

Free routing

SlugMeaning
openrouter/free Free Models Router: filter free models by request capabilities, then pick one at random. $0 for router + free upstreams.
provider/model:free Free variant: pin a specific free catalog entry. Use when you need a known model, not a random free pick.

Free lists churn hard: a :free slug can 404 as “unavailable for free” while the paid slug still works (seen with former free pins like meta-llama/llama-3.2-3b-instruct:free and tencent/hy3:free). Prefer openrouter/free for exploration; pin only a slug you just verified (router response or models?q=free). Always compare requested vs returned model.

Models catalog

GET /api/v1/models returns live catalog metadata for pickers (Bridge). Prefer server-side sort / filters over downloading everything.

FieldUse
idSlug for Chat Completions model
pricing.prompt / completionUSD per token (string); "0" = free; ×1e6 → $/M display
supported_parameterse.g. tools, structured_outputs
context_lengthMax context window
 
// Cheapest tool-capable text models
GET /api/v1/models?supported_parameters=tools&sort=pricing-low-to-high&limit=15

// Free-tier prompt price ($/M)
GET /api/v1/models?max_price=0&sort=pricing-low-to-high

List price ≠ billed cost: catalog pricing is the sticker; usage.cost on a completion is what you paid.

Usage, cost, latency

Every Chat Completions response includes usage automatically (Usage Accounting). No include flag — older options are deprecated.

SignalWhere
Tokens usage.prompt_tokens / completion_tokens / total_tokens (native tokenizer)
Your bill usage.cost — credits charged for this call (SDK types may omit it; it is on the JSON)
Latency Measure client-side around the await; optional audit via GET /api/v1/generation?id=… 
const t0 = performance.now();
const completion = await client.chat.completions.create({ … });
const latencyMs = Math.round(performance.now() - t0);
console.log(completion.model, completion.usage, latencyMs);

Log model + tokens + cost + latency_ms on every call — the habit Fusion and Bridge need before “which model won?” debates.

Provider prefs & fallbacks

One model slug can be served by many upstreams. OpenRouter recovers in two layers:

LayerDefaultConfig
Provider failover (same model, next host) On provider: order, only, ignore, allow_fallbacks, sort
Model fallbacks (different model) Off models array in priority order 
{
  "model": "openai/gpt-4o-mini",
  "provider": { "sort": "latency", "allow_fallbacks": true },
  "models": ["google/gemini-2.5-flash"],
  "messages": [ … ]
}

Slug shortcuts: :nitro → sort throughput; :floor → sort price. Audit who served you: GET /api/v1/generation?id=… → provider_name. Narrowing only/ignore/order reduces recovery options.

Fusion

Fusion runs a panel in parallel, a judge that returns structured analysis (consensus, contradictions, insights, blind spots), then a final answer. Use when cost-of-wrong > sum of extra completions. Bill = all underlying completions.

EntryShape
Alias model: "openrouter/fusion" (Quality defaults)
Plugin plugins: [{ id: "fusion", preset | analysis_models, model }]
Server tool tools: [{ type: "openrouter:fusion" }] — force with tool_choice: "required" 
"plugins": [{ "id": "fusion", "preset": "general-budget" }]
// presets: general-high | general-budget | general-fast
// explicit analysis_models / model override preset

Catalog / lab: openrouter/fusion, server tool docs.

Fusion
OpenRouter multi-model deliberation: panel → judge analysis → outer final answer. Alias openrouter/fusion, plugin id: "fusion", or tool openrouter:fusion.

Pareto Code Router

Pareto Router (openrouter/pareto-code) is coding-only: set min_coding_score (0–1) → AA coding percentile tier → cheapest available in-tier (or fastest with :nitro). Same-tier fallbacks on transient errors. No router fee — you pay the underlying model. Shortlist evolves; pin a slug for stable evals. 

"model": "openrouter/pareto-code",
"session_id": "…",  // pin model+provider for multi-turn / cache
"plugins": [{ "id": "pareto-router", "min_coding_score": 0.5 }]
ScoreTier
>= 0.66 / omittedhigh (default)
0.33–0.66medium
< 0.33low
Pareto Router
Coding router: quality floor via min_coding_score, then cheapest (or :nitro) in tier. Alias openrouter/pareto-code, plugin id: "pareto-router".

OpenAI SDK drop-in

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://openrouter.ai/api/v1",
  apiKey: process.env.OPENROUTER_API_KEY,
  defaultHeaders: {
    "HTTP-Referer": "https://your-site.example",
    "X-OpenRouter-Title": "your-app-name",
  },
});

Optional headers help rankings on OpenRouter; they are not required for a successful call.

Glossary seeds

Gateway
A service that accepts one client protocol and routes to many upstream model providers (OpenRouter, PPQ.ai).
Provider (OpenRouter sense)
The upstream that actually runs the model (OpenAI, Anthropic, Together, …). One model slug can be served by multiple providers.
Provider (Inference Bridge sense)
An adapter in the extension (openai, ollama, soon openrouter) that implements streamChat.
Router (OpenRouter)
A special model id that selects among other models (e.g. openrouter/free). Not itself an upstream model — read the returned model.
Variant suffix
A : suffix on a model id that selects a catalog variant — e.g. :free for the free tier of that model.
Provider failover
Automatic try of another upstream for the same model when the chosen provider errors (default allow_fallbacks: true).
Model fallback
Opt-in walk of a models list when the primary model cannot complete (downtime, 429, context, moderation).

Inference Bridge mapping

Bridge’s OpenAI adapter posts to api.openai.com/v1/chat/completions. An OpenRouter adapter is the same shape with:

  • URL → https://openrouter.ai/api/v1/chat/completions
  • Key → OpenRouter key
  • Models → provider/model catalog (static list or GET /models)
