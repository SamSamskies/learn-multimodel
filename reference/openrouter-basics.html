OpenRouter Basics

One OpenAI-compatible endpoint. Many models. You still own routing decisions.

Endpoints

UseURL
Chat Completions (apps / Bridge) https://openrouter.ai/api/v1/chat/completions
OpenAI SDK baseURL https://openrouter.ai/api/v1
Cursor BYOK override https://openrouter.ai/api/v1/cursor
List models GET /api/v1/models

Auth

Authorization: Bearer sk-or-v1-...

Keys live at openrouter.ai/settings/keys. Credits are separate from Cursor Pro and OpenAI platform billing.

Model IDs

openrouter/free
openai/gpt-4o-mini
anthropic/claude-sonnet-4
google/gemini-2.5-flash
provider/model:free   ← pin only after confirming it is still free

Prefer provider/model slugs from openrouter.ai/models. Router aliases like openrouter/free pick among matching models for you — log the returned model to see what ran. Some catalog entries use a ~ prefix — copy the exact string from the docs.

Free routing

SlugMeaning
openrouter/free Free Models Router: filter free models by request capabilities, then pick one at random. $0 for router + free upstreams.
provider/model:free Free variant: pin a specific free catalog entry. Use when you need a known model, not a random free pick.

Free lists churn hard: a :free slug can 404 as “unavailable for free” while the paid slug still works (seen with former free pins like meta-llama/llama-3.2-3b-instruct:free and tencent/hy3:free). Prefer openrouter/free for exploration; pin only a slug you just verified (router response or models?q=free). Always compare requested vs returned model.

Usage, cost, latency

Every Chat Completions response includes usage automatically (Usage Accounting). No include flag — older options are deprecated.

SignalWhere
Tokens usage.prompt_tokens / completion_tokens / total_tokens (native tokenizer)
Your bill usage.cost — credits charged for this call (SDK types may omit it; it is on the JSON)
Latency Measure client-side around the await; optional audit via GET /api/v1/generation?id=… 
const t0 = performance.now();
const completion = await client.chat.completions.create({ … });
const latencyMs = Math.round(performance.now() - t0);
console.log(completion.model, completion.usage, latencyMs);

Log model + tokens + cost + latency_ms on every call — the habit Fusion and Bridge need before “which model won?” debates.

OpenAI SDK drop-in

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://openrouter.ai/api/v1",
  apiKey: process.env.OPENROUTER_API_KEY,
  defaultHeaders: {
    "HTTP-Referer": "https://your-site.example",
    "X-OpenRouter-Title": "your-app-name",
  },
});

Optional headers help rankings on OpenRouter; they are not required for a successful call.

Glossary seeds

Gateway
A service that accepts one client protocol and routes to many upstream model providers (OpenRouter, PPQ.ai).
Provider (OpenRouter sense)
The upstream that actually runs the model (OpenAI, Anthropic, Together, …). One model slug can be served by multiple providers.
Provider (Inference Bridge sense)
An adapter in the extension (openai, ollama, soon openrouter) that implements streamChat.
Router (OpenRouter)
A special model id that selects among other models (e.g. openrouter/free). Not itself an upstream model — read the returned model.
Variant suffix
A : suffix on a model id that selects a catalog variant — e.g. :free for the free tier of that model.

Inference Bridge mapping

Bridge’s OpenAI adapter posts to api.openai.com/v1/chat/completions. An OpenRouter adapter is the same shape with:

  • URL → https://openrouter.ai/api/v1/chat/completions
  • Key → OpenRouter key
  • Models → provider/model catalog (static list or GET /models)
